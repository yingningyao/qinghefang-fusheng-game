# 清河坊浮生记

以南宋临安市井生活为主题的单人浏览器游戏。玩家与电脑邻里阿文争取订单，在七日后比较经营得分。

打开网站，新玩家选择“初来乍到”，三步完成第一单；熟悉玩法者选择“熟门熟路”，自由接单。不需要注册或登录，进度保存在当前浏览器。旧版存档可以继续，体验完整竞争规则建议新开一局。

## 怎样玩

- 每天4行动，玩家每办一件事，阿文回应一次，双方各用自己的行动预算。单数日玩家先手，双数日阿文先手。
- 每日三份订单，抢走当日不补。在任意地点可留单，取货和办理须到对应店铺。抢手单按时完成额外获得2钱、3分。
- 双方共用每日备料与脚夫：供货铺每天1批备料，脚夫每天可雇2次。取货后可以亲自送，也能花钱、用1行动雇人送，自己留在原地。留单要看费用、路程和交期。
- 履约每单4分、抢手单额外3分、信用每点2分（最多12）、钱每枚1分（最多20）、志向每段3分（最多9）；逾期每单减1信用、扣2分。同分平局。
- 历史故事随办事解锁，也可免费听取。故事不计分，不限制总分。主画面显示实时比分、阿文动向和资源余量。

## 地图与史料

御街上北下南，可切换全图、放大并找到自己的位置。点位、路线及行动费用为游戏安排，不是实测复原或现代导航。

“坊巷寻踪”提供16条整理后的证据记录、店铺与文献地段关系、原文与出处，并可设定行走目的地。三张参考图保持原样，支持放大、滚动与单独查看。未核定的制图出处、时代混合与字形差异保留说明。

主要依据包括《梦粱录》卷七、八、十、十三、十六，《都城纪胜》，《咸淳临安志》卷十九、二十一和《西湖老人繁胜录》。三元楼的后期更创、宗阳宫的沿革与同名桥梁分别处理；后期材料不直接当作约1250年的同年城市快照。
