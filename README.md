# 清河坊浮生记

以南宋临安市井生活为主题的单人浏览器游戏。

打开网站后，新玩家选择“初来乍到”，按三步引导领取新幌、前往茶汤铺并交付；熟悉玩法者选择“熟门熟路”自由开局。每轮是一日，只有三次行动，需要在办差、挣钱、信用和收集故事之间作出取舍。

2026-09-26反馈修订版：手机竖屏面板切换与横屏三列布局、避开商铺的地图路线、委托倒计时、邻里意图和行动回顾、双方统一市情规则与志向计分、茶肆故事二选一、打听明日市情、终局史料索引与本局小记。

游戏中的“史料可知”与“本局情境”分别呈现史料依据和游戏创作。地图用于表达游戏路线，并非南宋临安的实测复原图。

游戏进度保存在玩家自己的浏览器中。试玩不需要注册或登录账号。
